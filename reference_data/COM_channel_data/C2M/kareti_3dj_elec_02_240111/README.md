# Kareti C2M channel subset

Source archive: kareti_3dj_elec_02_240111.zip (IEEE 802.3dj public electrical channel contribution, 2024-01-11).
This project stores the PCB_host/NoSkew Ml36_20 THRU, NEXT1 and FEXT1 Touchstone files used by the 178A report, small CI and full-search cases. Files are retained unchanged from the local extracted source archive. Runtime execution_plan.json records each input SHA256 hash. Case workbook channels sheets own selection; files are not duplicated under cases.

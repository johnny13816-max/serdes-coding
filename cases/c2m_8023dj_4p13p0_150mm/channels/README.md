# C2M Channel Files

This folder contains one complete channel set for the current case:

- `victim_thru.s4p`: victim / THRU channel.
- `next_1.s4p` ... `next_6.s4p`: NEXT crosstalk channels.
- `fext_1.s4p` ... `fext_5.s4p`: FEXT crosstalk channels.

The parent `config.xlsx` uses relative paths such as:

```text
channels/victim_thru.s4p
channels/next_1.s4p
channels/fext_1.s4p
```

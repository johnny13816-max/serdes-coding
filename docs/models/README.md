# Model documentation

Model documents explain semantic execution flow and data ownership. They are organized by COM version and then by stage.

- [93A](93A/README.md): 93A model documentation and native config contract.
- [178A](178A/README.md): 178A model documentation and native config contract.
- [93A versus 178A](93A_vs_178A.md): version comparison and migration context.

Each version will contain `call_tree.md`, `config_tree.md`, `status_tree.md`, and one contract per stage under `stages/`.

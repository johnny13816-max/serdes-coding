# CP-BR matrix（retired planning index）

本文件原本保存一份依 stage 排列的 branch coverage table，與正式 Branch
Registry 重複，並因此出現 stage、selector path 與 review status 不同步的問題。
自 2026-11-11 起不再於此維護 branch rows。

唯一權威紀錄：

- 分支分類總表：
  [178A Branch Behavior Registry](../models/178A/branch_behavior_registry.md#分支分類總表)
- ownership / function-position tree：
  [178A Branch Behavior Registry](../models/178A/branch_behavior_registry.md#分支-ownership--function-position-tree)
- 當前 review 順序與 integration gate：
  [Active contracts](active_contracts.md)

新分支、重新分類、owner 二次審查與 validation evidence 只更新 Branch
Registry；本 retired index 不再新增平行表格。
